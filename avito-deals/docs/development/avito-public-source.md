# Публичные объявления Avito в локальном интерфейсе

Приложение запрашивает только HTTPS-страницы `www.avito.ru` без авторизации.
Оно не следует на внешние сайты, не подделывает браузерные заголовки, не
использует прокси и не обходит CAPTCHA, антибот-защиту или ограничения. Ответы
403/429 и другие неуспешные статусы останавливают текущий импорт; автоматического
повтора HTTP-запроса нет. После HTTP 429 все сетевые запросы к Avito ставятся на
общую паузу: приложение учитывает `Retry-After`, а если заголовка нет или он
некорректен — ждёт значение `AVITO_RATE_LIMIT_FALLBACK_COOLDOWN` (по умолчанию
5 минут). Во время паузы новые HTTP-запросы не отправляются.
Пауза хранится в памяти и сбрасывается при перезапуске приложения.

## Запуск

Из корня репозитория:

```sh
if [ ! -f .env ]; then cp .env.example .env; fi
```

Установите в `.env` собственный случайный локальный `POSTGRES_PASSWORD`, затем:

```sh
docker compose up --build -d
```

Compose по умолчанию использует `AVITO_DEALS_INGESTION_SOURCE=avito`.
Можно явно выбрать `mock`, чтобы не делать сетевых запросов. Параметры:

| Переменная | По умолчанию | Значение |
|---|---:|---|
| `AVITO_DEALS_INGESTION_SOURCE` | `avito` | `avito` или `mock` |
| `AVITO_REGION_SLUG` | `rossiya` | Допустимый slug региона в URL поиска Avito |
| `AVITO_MAX_PAGES` | `2` | Лимит 1–5 страниц на один поисковый запуск |
| `AVITO_REQUEST_TIMEOUT` | `15s` | Timeout одного публичного HTTP-запроса |
| `AVITO_MINIMUM_REQUEST_INTERVAL` | `30s` | Минимальный интервал между HTTP-запросами, код не опустит его ниже 1 секунды |
| `AVITO_RATE_LIMIT_FALLBACK_COOLDOWN` | `5m` | Пауза после HTTP 429, если `Retry-After` отсутствует или некорректен |
| `AVITO_MAXIMUM_RESPONSE_BYTES` | `5242880` | Максимальный размер HTML-ответа |

Создайте активный поиск через страницу **«Поиски»**: укажите слова в запросе,
при необходимости город/категорию и ценовой диапазон. Город и категория
добавляются к тексту запроса, цены передаются как `pmin`/`pmax`; region slug
задаётся отдельно. Планировщик проверяет активные поиски раз в минуту, а сам
поиск запускает не чаще его `intervalMinutes`. Первый импорт начнётся на
ближайшем цикле планировщика.

Откройте **«Объявления»** и нажмите **«Обновить»** после выполнения импорта.
Название объявления открывается ссылкой на публичную страницу Avito. В
карточках, где feed не содержит состояние, оно сохранится как `UNKNOWN`.
Источником является feed; детали item-страницы и текст описания не сохраняются
в каталоге. Текст пропускается, чтобы случайно не сохранять контактные данные,
указанные в свободном описании объявления. Данные отображаются в каталоге, но
автоматически не превращаются в рассчитанные сделки: matching/pricing/scoring
для новых импортированных записей ещё не запускаются, Telegram здесь не
используется.

Импорт не считает результаты поиска полным снимком источника и не помечает
объявления удалёнными только потому, что они отсутствуют на текущей странице.
HTTP 429 означает, что Avito ограничил запросы; приложение не может гарантировать,
что ответ не возникнет, но прекращает запросы на время паузы. `Retry-After`,
если он прислан сервером, имеет приоритет и может быть больше fallback-паузы.
Не перезапускайте сервис многократно в этот период: это сбрасывает паузу и может
снова отправить запрос. Для полного отключения сетевого источника установите
`AVITO_DEALS_INGESTION_SOURCE=mock`.
Для диагностики смотрите логи backend:

```sh
docker compose logs -f backend
```
