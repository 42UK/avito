# ADR-001: Модульный монолит
Status: Proposed (ARCH-001) | Date: 2026-10-08

## Контекст
MVP, один домен, нужна скорость разработки и тестируемость.
## Решение
Один Spring Boot сервис, один PostgreSQL, строгие границы модулей внутри процесса, проверка ArchUnit. События in-process.
## Альтернативы
Микросервисы, Kafka, Redis — отклонены: избыточная сложность без подтверждённой нагрузки.
## Последствия
Простой деплой и отладка; границы держим дисциплиной и тестами. Выделение модулей возможно позже благодаря портам и событиям.
