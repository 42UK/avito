# Frontend

Отдельное SPA на Vite, React и TypeScript. Клиент обращается только к
реализованному REST API и не подключается к PostgreSQL.

## Запуск

```sh
npm install
npm run dev
```

Vite по умолчанию проксирует `/api` на `http://localhost:8080`. Для другого
backend URL задайте `VITE_PROXY_TARGET` в среде Vite. При необходимости прямого
доступа клиента вместо proxy задайте `VITE_API_BASE_URL`, например
`http://localhost:8080/api`.

```sh
npm test
npm run build
```

Реализованные экраны: обзор со статистикой, последними сделками и объявлениями;
списки сделок и объявлений с серверной пагинацией; CRUD сохранённых поисков;
страница сохранённой сделки с данными снимка рынка, оценками, сравнительными
объявлениями и выбросами, историей цены и объяснением. Все данные и пустые
состояния приходят из API; ошибки backend не подменяются демонстрационными
данными.

Для публичного Avito ingestion и просмотра сохранённых объявлений см.
инструкцию [Avito public source](../avito-deals/docs/development/avito-public-source.md).
